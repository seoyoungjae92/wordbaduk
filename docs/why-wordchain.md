# 앱인토스 게임 아이템 점검

점검 2026-09-20. 기준: **혼자 / 끝없이 / 실력이 느는 게 느껴지게 / 광고로 수익**

`README.md`의 조사는 "공공데이터 + 알림" 패턴 안에서만 돌았다. 이 문서는 그 프레임 밖,
**앱인토스에서 실제로 도는 것**을 기준으로 다시 본 결과다.

---

## 결론 먼저

**끝말잇기(적응형 AI + 단어 도감).**

초성퀴즈를 밀다가 바꿨다. 이유는 한 줄이다 —
> 끝말잇기는 사전이 **곧 게임**이고, 초성퀴즈는 사전을 **큐레이션해야** 한다.

## 1. 블로커 점검 — 둘 다 통과

### 1-1. 사전 데이터 라이선스 ✅

표준국어대사전은 2019-03-11 **CC BY-SA**로 전환됐고 Open API를 제공한다.
우리말샘도 CC BY-SA(2.0 KR). **상업적 이용 가능**하다.

- 표준국어대사전 Open API: data.go.kr 3057780 / stdict.korean.go.kr
- 우리말샘: data.go.kr 15105193
- 한국어기초사전: data.go.kr 15105059

⚠️ **SA(동일조건변경허락) 조항 주의.** 사전을 가공해 만든 결과물이 2차적저작물로 판정되면
그것도 CC BY-SA로 배포할 의무가 생긴다. 즉 **문제 세트를 경쟁자가 합법적으로 가져갈 수 있다.**

- 끝말잇기: 사전을 **판정용으로 조회**만 하므로 2차적저작물 논란이 작다. 유리.
- 초성퀴즈: 뜻풀이를 문제로 **가공**하므로 SA가 직접 걸린다. 불리.

앱 내 출처 표기는 어느 쪽이든 필수.

### 1-2. 게임물 등급분류 — 우회 경로 있음 ✅

앱인토스는 모든 게임에 GRAC 등급분류를 요구하고, **구글·애플의 IARC 등급은 국내 효력이 없다.**
하지만 토스 공식 문서에 **자체등급분류 경로**가 명시돼 있다:

1. 구글 플레이 / 앱스토어에 **먼저 출시**한다 (구글·애플은 자체등급분류사업자)
2. 거기서 연령 등급 설문으로 등급을 받는다
3. 앱인토스 콘솔 > 게임 등급분류 탭에 정보를 입력한다
   - 등록자명(구글=개발자명 / 애플=제공자명), 자체등급분류사업자명, 등급분류일자·번호
   - 자체등급분류 게임물 플레이 화면 2장 + 앱인토스 내 화면 2장
4. 미작성 시 **등급미필 게임물**로 간주 → 시정권고·수사의뢰·행정처분

→ **GRAC 직접 심의(10~15일 + 수수료)를 건너뛸 수 있다.**
   조건은 "동일한 게임"일 것. 플레이 화면으로 대조한다.
→ 부수 효과로 배포 채널이 하나 더 생긴다. 손해가 아니다.

## 2. "실력이 느는 느낌"의 진짜와 가짜

이번 점검에서 가장 중요한 필터.

| | 가짜 성장 | 진짜 성장 |
|---|---|---|
| 정체 | 레벨 숫자가 오름, 스테이지가 늘어남 | 전에 못 하던 걸 함 |
| 사용자 반응 | 2주면 눈치챈다 | 계속한다 |
| 예 | "레벨 47" | "'릇'으로 끝나도 이제 안 막힌다" |

진짜 성장의 조건은 셋 중 하나 이상이다.
- **레퍼토리 축적** — 아는 게 실제로 늘어난다
- **승률 상승** — 상대가 있어 측정된다
- **속도 향상** — 같은 걸 더 빨리 한다

순수 퍼즐(물 정렬, 사천성)은 셋 다 없다. **판만 늘어나고 나는 그대로다.**

### 탈락 사유

- **자모 조합 단어 만들기** — 「한글 퍼즐: 단어 찾기」(App Store id721510215)로 이미 존재.
  ID 번호상 2013년경 등록. **12년 넘게 있었는데 안 떴다.** 비어 있는 자리가 아니라 시도됐다 안 된 자리.
- **물 정렬·사천성류** — 성장 체감이 구조적으로 0. 님 기준의 핵심을 못 맞춘다.
- **숫자 만들기** — 글로벌 포화. 한국어라는 해자가 없다.

### 초성퀴즈를 보류한 이유 (앞선 판단 정정)

"사전 = (표제어 + 뜻풀이) 쌍이 그대로 문제 → 콘텐츠 무한"이라고 봤는데, **과했다.**

1. **표제어 대부분이 쓸 수 없다.** 수십만 중 고어·방언·전문용어가 압도적이다.
   실제로 쓸 만한 건 빈도 상위 1~2만 개.
2. **뜻풀이가 힌트로 안 된다.** 사전 정의는 순환적이거나 난해하다.
   "고기·두부·김치 따위를 넣고 끓인 찌개"는 좋지만 이런 건 소수다.
3. **초성은 답이 여러 개다.** ㄱㅅ → 가수/교실/기술/고생… 힌트 품질이 게임 품질 전부인데
   그게 자동화가 안 된다.

→ 기존 초성퀴즈 앱이 1,176문항에서 멈춘 건 게으름이 아니라 **큐레이션 병목**이었을 가능성이 높다.
   결국 수작업으로 돌아온다. "무한"이 아니다.

## 4. 왜 끝말잇기인가

### 4-1. 사전이 곧 게임이다

큐레이션이 필요 없다. **등재 여부만 판정**하면 된다.
고어·전문용어도 사전에 있으면 유효하고, 오히려 그게 재미다 — "그런 단어가 있어?"
초성퀴즈에서 독이었던 게 여기선 자산이 된다.

### 4-2. 성장이 물리적으로 쌓인다

끝말잇기의 실력 = **어려운 두음의 레퍼토리**.
- '릇'에서 막혔다 → 다음에 안 막힌다 → 이건 착각이 아니라 실제 능력이다
- 승률이라는 객관 지표가 매 판 나온다
- 셋 중 **레퍼토리 + 승률** 두 개를 동시에 만족하는 유일한 후보

### 4-3. 검증된 불만이 크게 쌓여 있다

Play에서 "끝말잇기" 검색 = 28개 이상, **전부 한국 개발사**.
plantymobile 7개, 피지선 5개, Flower&Technology 2개, OZMANOZCO 2개.

**그런데 평점이 3점대다** — 3.9 / 3.4 / 3.7 / 3.0 / 3.1 / **2.8** / 3.4 / 3.0
(같은 시장의 단어게임은 4.6~4.9)

불만의 정체가 앱 목록에 그대로 드러난다:
「끝말잇기 한방단어」「끝말잇기 고수사전 - 지능게임을 위한 전략」「한방단어 - 끝말잇기」
**한방단어 공략 앱이 따로 장사가 될 만큼 있다** = AI가 한방단어로 찍어눌러 유저가 진다.

> 사람들은 이기고 싶은 게 아니라 **아슬아슬하게 이기고 싶어한다.**

### 4-4. 설명이 필요 없다

한국인 전원이 규칙을 안다. 미니앱은 설치 장벽은 없앴지만 **학습 장벽은 남아 있다.**
첫 화면에서 튜토리얼을 읽어야 하는 게임은 미니앱에서 특히 불리하다.

## 5. 설계

### 5-1. 적응형 AI — 이게 제품의 전부다

승률을 **5~6할**에 붙들어 둔다. 기존 28개가 전부 이걸 안 해서 3점대다.

- AI가 쓸 수 있는 단어 풀을 사용자 실력에 따라 조절
- 한방단어는 **아껴 쓴다**. 항상 쓰면 사용자가 나간다
- 사용자가 3연승하면 조인다, 2연패하면 푼다
- 티 나면 모욕이다. **티 안 나게** 하는 게 난이도의 전부

### 5-2. 단어 도감 — 자랑거리 + 성장 증거를 한 번에

> 지금까지 쓴 단어 **1,847개** / 발견한 한방단어 **23개**

수집 구조가 세 가지를 동시에 푼다:
- **성장의 물리적 증거** (숫자가 진짜 내 것)
- **자랑거리** (남과 비교 가능)
- **다시 올 이유** (빈칸을 채우고 싶다)

레벨 숫자와 결정적으로 다른 점: **도감은 내가 실제로 한 일의 기록**이다.

### 5-3. 국어 급수

8급 → 1급 → 특급. 한국인은 급수를 설명 없이 이해한다(한자급수·컴활·토익).
**5060은 자격증 세대라 레벨보다 훨씬 강하게 꽂힌다.**

- **급수는 절대 안 떨어진다.** 떨어지면 스트레스라 이탈한다
- 대신 **승급 시험**이 있다. 조건을 채우면 해금, 한 판에 몰빵
- 떨어져도 급수는 유지 → 재도전 → 세션 증가

### 5-4. 광고

| 위치 | 유형 | 근거 |
|---|---|---|
| **승급 시험 재도전권** | 리워드 | 사용자가 진심으로 원하는 순간. 완주율 최고 |
| 한 번 무르기 | 리워드 | 막힌 순간이 구조적으로 자주 온다 |
| 3~5판마다 | 전면 | 과하면 이탈 |
| — | 배너 | 노출 1위지만 eCPM 꼴찌. 후순위 |

토스 공식 문서상 eCPM은 **리워드 > 전면 > 배너**.
보상은 **게임 내 소모품으로만** 한다. 현금성(토스포인트)으로 가면
서버 검증 + 어뷰징 방어 + 부당수익 환수 리스크가 붙어 차원이 달라진다.

### 5-5. 토스 전용 한 방

**전국 급수 분포.** "1급은 전국에 2,847명입니다."
앱인토스 MAU가 400만이라 이 숫자가 **진짜로 만들어진다.**
희소성은 주장이 아니라 증명돼야 자랑이 된다. 소형 앱은 못 하는 것.

## 6. 리스크

1. **끝말잇기도 신규 진입이 안 뜬다.** 28개가 이미 있고 대부분 조용하다.
   다른 건 딱 하나 — **앱인토스라는 설치 없는 유통 채널.**
   꼬들이 웹에서 30만 간 게(2022) 이 가설을 지지하지만 증명은 아니다.
2. **고수는 게임을 닫는다.** 한방단어를 외우면 끝말잇기는 풀린다.
   → 규칙 변형(두음법칙 on/off, 3글자 이상, 금지어 풀)으로 열어둬야 한다.
3. **적응형 AI가 티 나면 모욕이 된다.** 여기가 유일한 진짜 기술 난제다.
4. **CC BY-SA의 SA 조항.** 사전 가공물 배포 의무. 법률 자문 아님 — 확인 필요.
